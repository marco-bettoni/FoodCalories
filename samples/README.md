# Sample meal photographs

Small verification photographs for classroom demos:

- `verify/apple.jpg`
- `verify/banana.jpg`
- `verify/candy.jpg`
- `verify/chocolate.jpg`

Tips:

1. Use clear lighting and a single plate.
2. Keep file sizes under about 5 MB.
3. Do not commit photos of identifiable people unless you have permission.

The application accepts uploads through the Streamlit interface.
You do not have to store photos here for the app to work.
